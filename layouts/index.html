Documentation Code source

Fonctionnalités

Une base unique pour le personnel, les bureaux et les mouvements, cloisonnée par laboratoire.

Annuaire

Fiches du personnel : statut, groupe, nationalités, dates de contrat, recherche immédiate.

Plans des bureaux

Plans d'implantation par bâtiment : affectation, taux d'occupation, places libres à une date donnée.

Arrivées et départs

Suivi des mouvements, listes de tâches d'arrivée et de départ, journal des modifications.

Interroger

Interrogation des données en langage naturel, traduite en requêtes et cloisonnée par laboratoire.

Multi-laboratoire

Plusieurs laboratoires sur une même instance, avec des données et des droits séparés.

Import et export

Import du personnel depuis un modèle Excel fourni, export de l'annuaire.

Une API, deux clients

La même logique métier sert le client web et l'application macOS, maintenus à parité.

Serveur

API

Go (Huma v2) sur PostgreSQL. Authentification LDAP ou comptes locaux, rôles par laboratoire.

Client web

Navigateur

Interface SvelteKit, accessible sans installation.

Bureau

macOS

Application SwiftUI native.
