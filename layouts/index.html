Fonctionnalités

Tout le suivi « qui travaille où », au même endroit

Une base unique pour l'annuaire, les bureaux et les mouvements de personnel — cloisonnée par laboratoire.

📇

Annuaire

Personnel, statuts, groupes, nationalités, dates d'arrivée et de départ, avec recherche instantanée.

🗺️

Plans des bureaux

Plans interactifs : affectation par glisser-déposer, occupation en direct, places libres à une date donnée.

✅

Arrivées & départs

Checklists d'onboarding et d'offboarding, journal d'audit de toutes les modifications.

💬

Interroger (IA)

Posez vos questions en langage naturel : l'IA les traduit en requêtes, strictement cloisonnées par labo.

🏛️

Multi-laboratoire

Plusieurs labos sur une même instance, avec des données et des droits parfaitement séparés.

📊

Import / export Excel

Import du personnel depuis un modèle fourni, export de l'annuaire en un clic.

Une API, deux clients

Web et macOS, à parité

La même logique métier sert les deux clients : ce qui change d'un côté est répliqué de l'autre.

CLIENT WEB

Navigateur

Interface SvelteKit rapide et responsive, accessible partout, sans installation.

API

Serveur Go

API Huma v2 sur PostgreSQL : robuste, typée, documentée — le socle commun.

MACOS

Application native

Application SwiftUI native, pensée pour un usage bureau confortable au quotidien.
